# Sound effects inventory

What every sound effect in VoxelRacing is, where it came from, where it plays and
how to replace it. Read-only survey of commit `c347c10` (Prototype 006). Script
line numbers refer to that commit. Some files had uncommitted edits while this was
written, so the numbers may shift slightly.

No audio file was added, changed or deleted in any VoxelRacing commit on any

No Python, numpy or other offline audio generator is in the repository. The only
`.py` file is `docs/artwork/make_reference.py`, an artwork tool. Nothing uses
`AudioStreamGenerator`.

### How to replace a sound (custom asset system)

Source: `src/assets/asset_resolver.gd` (`get_audio`, lines 145-244), the contract in
`assets/README.md`, and the per-sound list in `docs/ASSET_SPECS.md` (section "Audio")
and `src/assets/asset_catalog.gd` (`AUDIO`, lines 201-228).

- **Folder:** `custom/audio/`. While developing, this is the project's `custom/`
  folder. In an exported Windows/Linux game, it is a `custom/` folder next to the
  executable. Subfolders mirror the logical name.
- **File name:** the logical name without the `template_` prefix. For example, to
  replace `assets/audio/weapons/template_explosion.ogg` (logical name
  `weapons/explosion`), use `custom/audio/weapons/explosion.ogg`.
- **Formats:** `.ogg` (Ogg Vorbis), `.wav` (RIFF/WAVE) or `.mp3`, tried in that order.
  The files are loaded at runtime from their bytes, so no Godot import or rebuild is
  needed. Changes apply after the game restarts. A missing or invalid file falls back
  to the template with a warning.
- **Loops** (`vehicles/engine_loop`, `vehicles/engine_load`, `vehicles/tire_squeal`,
  `ambience/ambience`): use **WAV** for a sample-exact seam, as `docs/BACKLOG.md`
  notes that OGG encoding trims samples. `AssetResolver.set_looping()` only handles
  OGG and WAV, so an **MP3 override of a looping effect would not loop**. Music has
  its own loop logic in `music_player.gd`.
- Unlike graphics, audio has **no "packaged plain-name" layer**: a file
  `assets/audio/<x>.ogg` without the `template_` prefix is ignored. The only lookup
  order is `custom/` override, then `template_` fallback.
- **Cannot be replaced this way:** all 12 Claude-generated `SoundKit` sounds.
  `SoundKit` builds `AudioStreamWAV`s in code and never asks `AssetResolver`, so no
  file in `custom/` affects them. Replacing one needs a code change, for example
  having `SoundKit.stream(name)` try `AssetResolver.get_audio(...)` first. The
  override paths given for them below are **suggestions only**. Nothing reads them
  today.
- **Shared names:** several inherited sounds are reused in more than one place.
  Replacing `ui/ui_move`, for example, also changes the weapon-switch click and the
  garage-workshop repair ticks. Each one's uses are listed in section 4.

## 2. How the Claude-generated sounds are made

`src/audio/sound_kit.gd` (whole file; added in `2c8093c` "P004 (in progress)…",
never modified since). Every sound is synthesised on first use and then cached for
the session:

- mono, 16-bit PCM, 22050 Hz (`RATE`)
- fixed random seeds, so a sound is identical on every run
- normalised to 0.85 peak; the crowd bed uses 0.6
- 2 ms end fade on one-shots
- converted to `AudioStreamWAV` by `_to_wav()` (lines 559-582)

The techniques are hand-written DSP:

- white noise
- RBJ biquad low-pass, high-pass and band-pass filters (`_biquad`)
- feedback echo (`_echo`)
- sawtooth "voices" through two formant band-passes (crowd)
- scattered noise-burst "clap grains"
- decaying inharmonic sine partials (metal)
- an additive band-limited pulse plus triangle (jingle)

`SoundKit.play()` (lines 67-85) spawns a self-freeing `AudioStreamPlayer` on the
**Effects** bus, with a small random pitch jitter. The Effects volume slider
therefore controls these sounds. Race-world calls go through distance-attenuated
wrappers:

- `VoxelRaceFx._sound()`: `src/voxel/voxel_race_fx.gd:60-67`. Silent beyond 900 px
  from the view centre and during fast-forward.
- `VoxelLife._shout()`: `src/voxel/voxel_life.gd:610-620`. At most one crowd
  reaction every 1.2 s, silent beyond 1100 px, and only on circuits with spectators.
  The Battle Royale arena has none.

Usage was wired in `b70d876` ("crowd sound, little rewards, debris rattle and
backfire pops"), `cda5454` (replay ceremony "whoosh, jingle") and `2c8093c`
(achievement-toast pop).
