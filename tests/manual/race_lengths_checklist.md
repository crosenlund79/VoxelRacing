# Race lengths — manual checklist (3 / 7 / 20 / 50 laps)

Run the project (F5). Purpose: compare the same drivers over different race lengths (for example whether Rocco does better with more time to overtake).

- [ ] Title: **LAPS: 3** button cycles 3 → 7 → 20 → 50 → 3; the choice is remembered after restarting the game.
- [ ] The GET READY panel shows "… 20 LAPS" etc.; **Tab** there cycles the length too (Left/Right mode, Up/Down weapons still work).
- [ ] RACE: the HUD shows LAP 1 / N; the race ends after exactly N laps; RESULTS says "RESULTS - N LAPS"; Fire to race again keeps N and the reversed grid.
- [ ] SPECTATE RIVALS: every auto-restarted race uses the same N; the history shows a **laps** row (and the weapons row) for each race; Position Counts unchanged.
- [ ] Long races (20 / 50 laps) finish with every car classified with a real time, with weapons ON and with No Guns, at normal and fast speed; nobody is cut off by a time limit.
- [ ] Driving, rivals' behaviour and weapons feel the same as before at every length.
