VoxelRacing - Prototype 002: A World of Voxels
==============================================

Miniature motorsport, block by block. Portable build: extract the folder
anywhere and run VoxelRacing.exe (VoxelRacing.console.exe shows a log
window). No installation needed.

Controls: see CONTROLS in the menu. Extra keys:
  V  cycle the camera: MINIATURE / HIGH / LOW / TOP-DOWN
  L  night lighting on / off

Graphics: Forward+ renderer (Vulkan, falling back to Direct3D 12, then to
OpenGL on older hardware). Each track's voxel world is built while "The
Little Race" loading screen runs.

custom/ : put your own art and audio here (car drawings become voxel cars).
